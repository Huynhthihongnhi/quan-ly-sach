# Decision report

State the delivered behavior and its verified limits first.

Include an Option / What it does / Cost / Risk / Recommended table only when a choice remains. Mark exactly one recommendation and explain it in one sentence.

**Done:** Name completed criteria and the behavior they establish.

**Evidence:** Link the commands, observations and artifacts that ran. Distinguish passed, failed, not run and blocked. Identify self-reported observations.

**Maintainability:** For substantial source changes, summarize changed-function complexity, duplication and abstraction review. Link comparable measurements when available; name missing metrics and explain retained hotspots. Keep this separate from correctness evidence.

**Next:** Name the next task in order, or none when complete.

**Decision needed:** Include only a blocking choice owned by the user.

**Known gaps:** Preserve unverified behavior, dissent and release gates.
